# Task 24 - Merge and Join DataFrames

## Overview
This task demonstrates how to combine DataFrames using Pandas merge, join, and concat operations.

## Topics Covered
- Inner join
- Left join
- Right join
- Outer join
- Merging selected columns
- Merging with different column names
- Joining using indexes
- Concatenating DataFrames vertically
- Concatenating DataFrames horizontally

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## File Included
- task24_merge_join_dataframes.ipynb

## Outcome
Learned how to combine datasets using different merging, joining, and concatenation techniques in Pandas.
